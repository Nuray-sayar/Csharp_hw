## Built-in Data Types in C#

**Integer types**
- sbyte, byte, short, ushort, int, uint, long, ulong, nint, nuint

**Floating-point types**
- float, double, decimal

**Other types**
- bool (true/false)
- char (single character)
- string (text)
- object (base type of all types)
